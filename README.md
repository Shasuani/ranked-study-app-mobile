# Ranked Study App — Mobile

The React Native client for [ranked-study-app-backend](https://github.com/Shasuani/ranked-study-app-backend): a study timer that turns focus sessions into a ranked ladder. You finish a session, you earn XP and LP, and you climb through tiers and divisions.

Built with Expo and React Navigation.

## Built with

* Expo — build tooling and runtime
* React Native
* React Navigation — bottom tabs and native stack
* `expo-font` for the display typefaces

## Running it locally

```bash
npm install
npx expo start
```

Scan the QR code with Expo Go, or press `i` / `a` for a simulator.
